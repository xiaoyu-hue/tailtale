## 1. 概述

### 1.1 产品定位

**书时是一款以"养宠物"陪伴用户读书的网页应用，形态为游戏化阅读器 + 轻量工具箱。**

- 阅读是核心场景，宠物是情感招牌，工具箱是增值配件
- 开源作品：代码公开（Apache-2.0），文档共享（CC BY-NC 4.0）
- 无支付、无账号、无服务端依赖

### 1.2 产品原则

| 原则 | 说明 |
|---|---|
| 本地优先 | 电子书与用户数据不出浏览器，无需注册登录 |
| 零成本运营 | 无服务器、无数据库、无 AI 费用（BYOK 模式） |
| 游戏化驱动 | 阅读行为产生金币，金币养育宠物，形成习惯闭环 |
| 克制 | 每类功能只做与阅读场景相关的部分，不追求大而全 |

### 1.3 名词解释

| 术语 | 释义 |
|---|---|
| 书时 | 项目中文名，取"与书共度的时光"之意 |
| TailTale | 项目英文名，取"猫尾（tail）"与"故事（tale）"双关，呼应宠物陪伴读书的产品意象 |
| BYOK（Bring Your Own Key） | 用户自带大模型 API 密钥模式：密钥由用户自行申请并填入浏览器，调用成本由用户承担 |
| PWA（Progressive Web App） | 可"添加到主屏幕"、离线可用的网页应用形态 |
| 金币 | 站内虚拟积分，仅通过阅读行为获取，不可购买 |
| 打卡 | 每日阅读时长达标记录，支持连续天数统计 |

## 2. 目标与成功标准

### 2.1 目标用户

1. 开发者本人（第一验收人，每日真实使用）
2. 开发者社交圈（小范围试用与反馈）
3. 游戏化习惯养成爱好者
4. 愿意自行申请 DeepSeek 密钥体验 AI 解读书的极客用户

### 2.2 成功标准（可验证）

| 时间 | 标准 |
|---|---|

## 3. 功能架构

### 3.1 金币经济闭环

```
        赚取                          消耗
   ┌────────────────┐         ┌──────────────────┐
   │ 阅读计时        │         │ 宠物零食（好感度） │
   │ 连续打卡奖励    │  ────▶  │ 宠物外观/装扮     │
   │ 读完一本书      │  金币   │ 阅读主题皮肤      │
   └────────────────┘         └──────────────────┘
```

设计原则：

- 金币只能赚取，不可购买（与无支付定位一致）
- 先跑通"读书 → 金币 → 宠物成长 → 更想读书"的循环，数值后续调整

#### 3.1.1 赚取规则

| 行为 | 金币 | 说明 |
|---|---|---|
| 阅读计时 | 每 30 分钟 +10 | 核心水源，按本地累计分钟数折算 |
| 完成番茄钟（工具箱） | 每个 +5 | 与专注工具联动 |
| 每日打卡 | +5 | 当日阅读满 1 分钟即达成 |
| 连续打卡加成 | 第 3 天起 +2/天，上限 +10/天 | 奖励坚持 |
| 读完一本书 | +100 | 单次最大奖励 |

日收入参考：每天阅读 1 小时约 35~40 金币；轻阅读日（30 分钟）约 20 金币。

#### 3.1.2 消耗规则（宠物商店）

| 商品 | 价格 | 效果 |
|---|---|---|
| 免费抚摸 | 0 | 好感度 +1，每日 2 次 |
| 小鱼干 | 20 | 饱食度 +30，好感度 +2 |
| 逗猫棒 | 30 | 心情 +40，冷却 4 小时，消耗精力 15 |
| 猫条 | 50 | 饱食度 +50，好感度 +8 |
| 猫薄荷 | 80 | 全属性 +20，好感度 +15 |
| 皮肤：橘猫 | 200 | 外观 |
| 皮肤：三花 | 400 | 外观 |
| 皮肤：黑猫 | 600 | 外观 |
| 阅读主题皮肤 | 300 | 阅读界面主题 |

> 补充说明（2026-10-21）：①免费抚摸次数原稿 §3.1.2 记 3 次、§5.2 记 1 次，两处不一致，按用户决策统一为 **每日 2 次**；②逗猫棒即"玩耍"行动，精力不足 15 时不可用（需睡觉回复），睡觉中不可进行任何互动；③睡觉/唤醒为免费行动，规则见 §5.2；④**即买即用、无库存**（1.3.0 落地口径）：四件零食购买后立即生效，不进入背包；皮肤类商品（装扮线）缓建，商店页以"规划中"展示，解锁入口后续版本上线。

#### 3.1.3 平衡与防通胀

- 日收入与日常消耗（1 份小鱼干）大致持平，余量约 10~20 金币/天，攒一个基础皮肤约 2 周
- 金币无其他来源、无交易功能，商店是唯一出口，天然防通胀
- 好感度每日获取上限 +10（防刷）；成长阶段阈值：少年猫 50 / 成年猫 150 / 完全体 400，配合阅读时长加好感，完全体约 2~3 个月的长线目标。成长值按累计获得的好感度计算、只增不减、封顶 400（防止阶段倒退；当前好感度被冷落会下降，二者分离）；阈值即晋级线，故实际分四档：小猫（<50，2026-10-21 用户定名）/ 少年猫（50–149）/ 成年猫（150–399）/ 完全体（400）
- 数值为 v1 初值，上线后依真实使用数据调整

## 5. 核心系统设计

### 5.1 阅读与打卡（P0）

- 阅读计时：页面可见且书籍打开时累计，切后台/锁屏暂停
- 进度记忆：按书籍文件内容（而非文件名）记录位置，同一文件换设备可续读
- 连续打卡：按本地时间判定"今日是否阅读 ≥1 分钟"；每周 1 次豁免机会，避免中断挫败
- 经验值：阅读分钟数换算 XP，仅用于解锁公版书库与称号，不影响功能

### 5.2 宠物系统（P0）

- **无死亡机制**：宠物不会饿死；不喂食仅好感度缓慢下降，宠物会"表示想念"，永远存活
- **物种：第一版仅猫**。猫"陪伴但不打扰"的气质契合安静的阅读场景（狗需要高频互动，与沉浸阅读冲突）；单物种使工作量减半。架构按"物种配置化"设计（外观、属性衰减速率、零食类型均为配置数据），狗作为后续扩展加入，不改结构
- 三项属性：饱食度、心情、精力，按"天"级速度缓慢下降（初值：饱食 -30/天、心情 -20/天、精力 -20/天；离线按时间戳差分结算，一次最多结算 7 天，防设备长期关机/改时钟造成断崖）
- 互动：喂食/玩耍消耗金币；每天 2 次免费抚摸（建立每日打开习惯钩子）
- 睡觉行动（免费）：猫可入睡/唤醒。睡觉时饱食衰减减半、心情不衰减、精力随时间回复（每小时 +10，单次最多 +40）；睡醒好感 +1（计入每日上限）。睡觉中不能喂食/玩耍/抚摸——精力见底时的恢复手段，同时堵住"挂机睡觉刷属性"的口子
- 想念机制：饱食度 ≤20 时，每过一整天好感度 -2（不足一天不罚；睡觉减半衰减天然提供保护）
- 好感度与成长：喂食、玩耍、阅读时长均可提升好感度（每日获取上限 +10，防刷）；成长阶段阈值见 §3.1.3，外观随阶段变化
- 皮肤：橘猫/三花/黑猫三款用金币解锁（见 3.1.2）
- 情感钩子：连续阅读 30 分钟，猫会"蹭屏幕"撒娇。数值口径（1.3.0 落地）：阅读会话每累计满 30 分钟，好感 +5（计入每日上限）、未看羁绊 +1；猫视图/首页预览挂载时播放蹭屏幕动画并展示横幅，计数清零；已触发次数随会话落库，刷新不重触发。跨满 30 分钟块同时照常发放该块的金币奖励（与阅读奖励同口径）

### 5.3 AI 解读书（P1，BYOK）

- 设置页：DeepSeek 预设 + 自定义 OpenAI 兼容端点（base_url / api_key / model 三字段），覆盖所有 OpenAI 兼容大模型
- 密钥仅存浏览器本地，界面显著提示"不要在公共电脑填写"
- 功能：①全书大纲/摘要 ②针对书中内容提问 ③文字版思维导图
- 成本控制：调用前弹窗预估费用；不设服务端限额（密钥归用户，滥用成本由用户自担）
- 规范：AI 生成内容标注"AI 生成，仅供参考"

### 5.4 工具箱（P1，4~6 款）

第一版确定 6 款（均本地计算、无后端）：

| # | 工具 | 说明 | 选型理由 |
|---|---|---|---|
| 1 | 专注番茄钟 | 25/5 可配置，完成奖励金币（见 3.1.1） | 长青热门品类（Forest/潮汐/Focus To-Do 长期占据效率榜），且与金币体系联动 |
| 2 | 白噪音环境音 | 雨声/森林/咖啡馆/篝火等 | 专注类应用标配；用 Web Audio API 程序化合成，零音频文件、零授权问题 |
| 3 | 阅读统计日历 | 月度热力图（GitHub 贡献图样式） | 游戏化产品流行的可视化形态，直接复用打卡数据 |
| 4 | 文本统计 | 粘贴文本输出字数与预计阅读时长 | 轻量，与阅读强相关 |
| 5 | 书摘导出 | 阅读中选中文字保存，批量导出 Markdown | 真实读者需求，衔接本地备份 |
| 6 | 今日一书 | 从内置公版库随机推荐一本 | 轻量运营向，提升公版库使用率 |

候选中「TXT/EPUB 格式转换」因前端实现复杂、收益低，移出第一版。

### 5.5 数据备份（P1）

- 全部数据存浏览器本地（localStorage / IndexedDB）
- 提供 JSON 导出/导入，作为换设备与清理缓存的恢复手段

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 隐私 | 用户密钥、书摘、阅读数据不出浏览器 |
| 兼容 | Chrome/Safari/Edge 近两年版本；移动浏览器可用；支持 PWA 添加到主屏幕 |
| 性能 | 首屏 2 秒内可交互；大 EPUB（>10MB）按章节懒加载 |
| 合规 | 代码 Apache-2.0、文档 CC BY-NC 4.0；「关于」页完整开源致谢；不提供盗版书源 |
| 无障碍 | 支持系统深浅色；正文字号可调 |

## 7. 技术架构

技术选型、架构图与约束详见《书时-技术栈.md》。摘要：

```
浏览器（React + Vite + PWA）
 ├─ 阅读引擎：epub.js / pdf.js（本地解析，书不出浏览器）
 ├─ 游戏逻辑：打卡/XP 逻辑 + 宠物逻辑（本地存储）
 ├─ AI：fetch 直连 DeepSeek（已实测支持 CORS，无后端）
 └─ 数据：localStorage / IndexedDB

托管：Cloudflare Pages ← GitHub 推送自动部署（GitHub Actions）
```

## 8. 合规与风险

详见《书时-开源组件与合规.md》。摘要：

| 项 | 状态 |
|---|---|
| 支付合规 | 无支付功能，无商户资质要求 |
| AI 监管 | BYOK 模式定位为"工具提供者"；不公开推广、小范围使用 |
| 版权 | 不内置盗版书源；内置仅公版书；用户导入文件来源由用户自担 |
| ICP 备案 | 境外托管试水期无需备案；国内正式访问需域名备案（要求申请人年满 18 周岁） |
| AI 内容标识 | 所有 AI 生成内容显著标注 |
