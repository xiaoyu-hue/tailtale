## 2. 书时的许可证义务

书时采用分层许可证：

| 对象 | 许可证 | 义务 |
|---|---|---|
| 书时自有源代码 | Apache-2.0 | 随仓库提供许可证全文；保留版权声明；修改文件需标明变更（Apache-2.0 §4a）；保留第三方 NOTICE（如适用） |
| 第三方组件 | 各自原许可证（MIT / Apache-2.0 等） | 保留原作者版权与许可声明，不得删除或改写 |
| 书时文档（docs 目录及三份项目文档） | CC BY-NC 4.0 | 保留署名；未经许可不得商业使用 |

履行方式：

- 仓库根目录 `LICENSE`：Apache-2.0 全文
- 仓库 `THIRD_PARTY_NOTICES`：第 1 节全部第三方组件的版权与许可证声明
- 应用内「关于 / 致谢」页：完整列出第三方组件、作者与许可证
- 每份文档头部元信息表标注 CC BY-NC 4.0；README 说明许可证分区（README 视为仓库组成部分，采用 Apache-2.0）
- 经修改的第三方源码文件：保留原版权声明并注明"由书时修改"

兼容性说明：Apache-2.0 与 MIT、Apache-2.0、BSD 类宽松许可证兼容（合并分发时保留各方声明即可）。第 1 节全部组件均在此列，无 GPL/AGPL 组件，许可证链条干净。

## 3. 禁用组件记录

以下项目经评估**不采用**，记录原因以防后续误用：

| 组件 | 许可证 | 不采用原因 |
|---|---|---|
| Koodo Reader | AGPL-3.0 | 传染性许可证：使用其代码则书时整体必须同样以 AGPL 开源 |
| Readest | AGPL-3.0 | 同上 |
| Anx Reader | GPL-3.0 | 同上（GPL 传染性） |
| Habitica | GPL v3（素材 CC-BY-NC-SA） | 代码传染；美术素材禁止商用，仅可参考其金币/经验设计思路 |
| Sube3494/toolsbox | 无许可证文件 | 无许可证即"保留所有权利"，法律上不可复制，仅可参考设计 |

**原则**：书时只集成 MIT / Apache-2.0 / BSD 类宽松许可证组件；GPL/AGPL 组件一律不集成；无许可证代码一律不复制。

| 维基文库 | 覆盖面广，含四大名著、鲁迅、唐诗宋词 | 文本多为 CC BY-SA 或公有领域；内置时保留文本原样、标注来源与许可证，不做改编（单纯格式转换按 CC 通行理解不构成改编，实施时以 CC 官方 FAQ 为准） |
| Project Gutenberg | 少量中文书 + 英文公版 | 公有领域，保留署名 |

## 5. 合规风险台账

| 风险项 | 现状与应对 |
|---|---|
| 支付合规 | 产品无支付功能，不涉及商户资质 |
| AI 服务监管 | BYOK 模式下书时定位为"工具提供者"，非 AI 服务提供者；密钥与调用成本归用户；不公开推广、小范围使用。若未来公开运营且用户量增大，需评估算法备案要求（生成式 AI 服务面向公众提供原则上需备案） |
| ICP 备案 | 试水期使用境外托管（Cloudflare），无需备案；面向国内用户的正式访问需域名 ICP 备案，备案主体须年满 18 周岁 |
| 内容合规 | 所有 AI 生成内容显著标注"AI 生成，仅供参考"；内置内容仅限公版书 |
| 用户隐私 | 用户密钥、书摘、阅读数据均不出浏览器；无任何服务端数据收集 |
| 密钥安全 | 密钥仅存用户本人浏览器 localStorage；界面提示勿在公共电脑填写；代码中禁止出现上传、传输用户密钥的逻辑 |
