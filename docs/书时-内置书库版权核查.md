# 书时内置公版书库版权核查

> 本文档记录书时「精选书库」（M7）内置公版书的版权核算、来源溯源、清洗流程与合规边界。
> 随代码变更同步更新；内置书单发生任何增减，必须先在本文件登记核查结论，再进代码。

## 1. 法律规则与时点判定

**规则**：依《中华人民共和国著作权法》，作品的著作财产权保护期为作者终身及其去世后 50 年，截止于作者去世后第 50 年的 12 月 31 日。合作作品以最后去世的作者计算。

**判定时点**：2026 年 10 月（本文档撰写与首批上架时点）。据此，作者须于 **1975 年 12 月 31 日** 前去世，其作品方进入公有领域。

**编者作品**（《唐诗三百首》《宋词三百首》属编选本）：除注意所收诗作的公有领域状态外，编选本本身的独创性编排亦可能受保护——本库**只取单篇作品原文，不复制任何编选本的编排顺序、注释与评点体系**，故不涉及编者权利。

**译本**：首批书单全为中文原本（或经繁转简的同一语言文本），无译本因素；如未来引入译本，须按译者卒年独立计算保护期。

**关于古腾堡 #27166 的说明**：该电子书是「《呐喊》自序 + 《阿Q正传》全文 + 大量古腾堡注释」的混合文件，并非《呐喊》单行本（《呐喊》共 14 篇，此处仅含自序与《阿Q正传》）。若整体上架为《呐喊》名不副实，故仅提取其中完整的《阿Q正传》（第一章序至第九章大团圆共 9 章）上架；《呐喊》完整篇目待可靠单行本源出现后按本文件流程核查补入。

**关于源仓库未附许可证的说明**：上述仓库均为纯文本数据仓库，内容为公有领域古籍原文。公有领域作品不受著作权保护，任何人均可使用、复制与分发，不因源仓库未声明许可证而受限；书时仅取其公有领域原文，不复制各仓库特有的目录编排、元数据或加工层信息。此判断同时记录于[开源组件与合规](书时-开源组件与合规.md)第 4 节与第 5 节风险台账。

**后续换源策略**：若上述仓库关停或改版，优先换用带明确许可证的等价源（如 Project Gutenberg、明确 CC0/公有领域声明的古籍库），换源后须重跑清洗管线、重算指纹并更新本表。

## 4. 清洗流程（上架前必经）

清洗管线（`scripts/clean_books.py`，构建期离线执行，源文本自备）对每本书依次执行：

1. **去包装**：剥离 ctext 站点页头页脚 / 古腾堡 START–END 标记之间的正文提取；剔除 HTML 标签、"Produced by" 类电子化署名行、"全文完"标记。
2. **结构规整**：删除段首全角缩进（阅读器自绘排版）；折叠相邻重复行；剔除日式排版残留的假名注释符号（`＿` 等）。
3. **字符归一**：去 BOM；CRLF/CR → LF；清除控制字符；压缩空行；行尾空格修剪。
4. **繁简统一**：OpenCC `t2s`（繁体 → 简体）。已验证转换质量：古诗文用字（「無」「爲」「著」等）转换正确，无人名用字误伤。
5. **红楼梦专项**：HLM-txt 的 120 个分回 markdown 文件按序拼装，剔除文件间的元信息行。
6. **指纹归档**：对清洗后文本计算 hashText 指纹（与书架「按内容续读」同一算法），写入 `public/library-manifest.json`；领取时以指纹校验，文件被篡改或损坏则拒绝入库。

**章节识别现状**（阅读器 `HEADING_RE` 识别「第 X 章/回」整行）：

| 书名 | 章节导航 | 说明 |
|---|---|---|
| 红楼梦 / 三国演义 / 西游记 / 水浒传 | ✅ | 「第一回」等标题行完整 |
| 道德经 | ✅ | 「第一章」等 81 章 |
| 阿Q正传 | ✅ | 「第一章序」至「第九章大团圆」9 章完整 |
| 论语 / 世说新语 / 唐诗三百首 / 宋词三百首 | ➖ 单章 | 篇名为「学而第一」「其一」等格式，不匹配「第 X 章」正则；**不为此修改阅读器正则**（避免影响用户自有导入书的章节识别），记录为已知限制 |

## 5. 分发与校验机制

- **书单**（`public/library-manifest.json`，约 2KB）：随应用分发，离线可见列表。
- **书籍本体**（`public/library-books/`，10 本共约 9.5MB）：随应用同源分发。领取时经「读取 → hashText 指纹校验 → 落 IndexedDB」链路，与用户本地导入的书走完全相同的数据通路（同样可阅读、计时、赚金币）。
- **不随备份导出**：内置书内容不进入用户备份包（备份只含导入书与数据）；换设备恢复后按需重新领取。此决策的完整权衡见方案文档《书时-M7-内置公版书方案.md》。

## 6. 已知限制与未上架书目

- **《呐喊》完整篇目**：古腾堡 #27166 为「自序 + 阿Q正传 + 注释」混合文件，非《呐喊》单行本，暂仅上架提取出的《阿Q正传》（详见第 3 节）；《呐喊》余下 12 篇待可靠单行本源出现后核查补入。
- **《骆驼祥子》（老舍）、《朱自清散文》**：老舍卒于 1966 年（+50 年 = 2016 年末届满）、朱自清卒于 1948 年，均为公有领域；但调研中**未找到可靠来源**——维基文库域名在本环境不可达，其他可访问仓库多带「版权归出版社所有」的盗版声明（现代整理本侵权）。首批暂不上架，待可靠源（如古腾堡明确授权版）出现后按第 2、3 节流程核查补入。
- **《庄子》**：原计划书单在列（cText 源），首批交付时因优先保证已核查书目的清洗质量未上架，与上述两本一并在后续批次补充。
- **源文本乱码残留**：清洗时发现个别源文件含编码损坏字符（如《红楼梦》「尤氏プ沐已毕」中的「プ」、《水浒传》对话中的「ぞ」），均为日文假名区字符，按编码损坏处理剔除；古籍以多源互校的更佳版本上架列为后续优化项。

## 7. 边界声明

- 书时不提供、不索引任何盗版书源；精选书库只上架经本文件核算的公版书。
- 「还想找更多？」外链区仅链接第三方公版书库站点首页（中国哲学书电子化计划 / 维基文库 / 识典古籍 / 古腾堡计划），外链站点的内容与其版权状态由各站点自行负责。
- 用户本地导入文件的来源合规责任由用户自行承担（README「隐私与数据」同措辞）。
